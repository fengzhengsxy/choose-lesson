# 中科大选课监控助手

面向中国科学技术大学教务系统的课程余量监控工具。程序定时查询目标课程的已选人数，发现空位后可以只提醒，也可以自动提交选课。

支持 Windows 图形界面，也可以在 Windows、Linux 和 macOS 中通过命令行运行。

> [!WARNING]
> 自动查询或自动选课可能触发教务系统风控，造成账号受限。请遵守学校规定，建议查询间隔不少于 60 秒。使用产生的后果由使用者自行承担。

## 主要功能

- 浏览并表格化显示全部可选课程；
- 按课程名称、英文名称、名称片段、跳字简称或 lessonId 模糊筛选；
- 允许少量错字，并按匹配程度排列结果；
- 区分课程名称、授课对象、教学班代码和课程代码；
- 查看选中课程的全部接口字段；
- 一键把 lessonId、课程名称和容量填入主界面；
- `monitor` 只监控，`spam` 自动选课；
- 支持随机查询间隔、活跃时段、异常熔断和提交失败熔断；
- 支持多门课程真正并行监控：每门课使用独立进程、独立计时和独立请求；
- 支持“所有课程分别抢到”和“任意一门成功即停止全部”两种完成策略；
- 主界面实时显示每门课的人数、状态、更新时间和最新消息；
- 成功课程自动保存为“已完成”，以后启动会自动跳过；
- 支持可选的 HTTP GET 通知地址；
- 登录态和配置只保存在本地项目目录。

## Windows 图形界面快速开始

### 1. 安装运行环境

首次使用时，在项目目录打开终端，依次执行：

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\playwright install chromium
```

以上步骤只需执行一次。

### 2. 打开助手

双击项目中的：

```text
启动抢课助手.bat
```

右上角会显示登录状态：

- `尚未生成登录态`：需要点击“登录教务系统”；
- `已登录过`：项目中已有 `auth.json`，但登录态过期后仍需重新登录。

### 3. 登录教务系统

点击“登录教务系统”，在弹出的浏览器中正常完成中科大统一身份认证。

登录成功后，程序会在项目目录生成 `auth.json`。该文件包含 Cookie 和本地登录状态，**不要发送给别人，也不要提交到公开仓库**。

### 4. 查找课程

可以使用两种方式：

#### 查看全部课程

点击“查看可选课程”，程序会弹出独立的课程结果窗口。

#### 模糊筛选课程

在“课程筛选”输入框中填写筛选条件，然后点击“模糊筛选名称或 ID”。支持：

- 完整名称：`计算机网络`；
- 名称片段：`计算机`；
- 跳字简称：`计网`；
- 少量错字：`计算机网路`；
- 英文名称或英文片段，不区分大小写；
- 完整或部分 lessonId。

筛选结果按匹配程度从高到低排列。

### 5. 看懂课程结果

结果窗口左侧为课程列表，包含：

| 字段 | 含义 |
|---|---|
| `lessonId` | 选课接口使用的教学班 ID，自动选课最重要的标识 |
| 教学班代码 | 具体教学班代码，例如 `AI3002.03` |
| 课程代码 | 课程本身的代码，例如 `AI3002` |
| 课程名称 | `course.nameZh`，真正的中文课程名 |
| 英文课程名 | `course.nameEn` |
| 授课对象 | 顶层 `nameZh/nameEn`，表示面向的专业、班级或学生范围，不是课程名 |
| 教师 | 授课教师 |
| 容量 | 课程容量上限 |
| 学分 | 课程学分 |

点击左侧课程后，右侧会用“字段—值”的方式显示该课程的全部接口信息。

确认课程无误后，可以：

- 点击“复制 lessonId”；
- 点击“填入主界面”，自动填写并保存 lessonId、课程名称和容量。

如果接口没有返回容量，需要回到主界面手动填写准确容量。

### 6. 设置运行参数

推荐设置如下：

| 界面字段 | 推荐值 | 说明 |
|---|---:|---|
| 学生关联 ID | 留空 | 登录后自动识别 |
| 选课轮次 ID | 留空 | 登录后自动识别；每学期会变化 |
| 课程 lessonId | 结果窗口一键填入 | 比课程名称更准确 |
| 课程名称 | 自动填入或留空 | 没有 lessonId 时用于模糊匹配 |
| 课程容量 | 必须准确填写 | 已选人数小于容量时才判断为有空位 |
| 查询间隔 | `60` | 活跃时段的基准查询间隔，建议不少于 60 秒 |
| 随机抖动 | `15` | 实际间隔为基准间隔上下随机浮动 |
| 非活跃心跳 | `300` | 非活跃时段的低频查询间隔 |
| 活跃时段 | `6:30-1:00` | 每天 6:30 至次日 1:00；1:00–6:30 不提交选课 |
| 异常熔断次数 | `20` | 连续网络或解析异常达到阈值后停止 |
| 提交失败熔断次数 | `3` | 连续选课失败达到阈值后停止，避免重复写请求 |
| 通知地址 | 留空或填写 HTTP 地址 | 见“通知地址”章节 |
| 隐藏浏览器窗口 | 按需勾选 | 登录时仍会显示浏览器，后台监控时可以隐藏 |
| 禁用浏览器沙箱 | 不勾选 | 仅受限 Linux 环境确有需要时启用 |

填写完成后点击“保存配置”。

### 7. 选择运行模式

| 模式 | 行为 |
|---|---|
| `monitor` | 发现空位后只记录并通知，不提交选课 |
| `spam` | 发现空位后自动提交选课，成功后退出 |
| `grab` | 与 `spam` 相同，保留作为兼容别名 |

建议第一次先使用 `monitor`，确认目标课程、容量和人数解析都正确，再改成 `spam`。

### 8. 开始和停止

点击“开始监控”，下方运行日志会持续显示查询结果。例如：

```text
已满 120/120
有空位！119/120
选课成功，退出。
```

需要结束时点击“停止”。关闭主窗口时，如果任务仍在运行，程序也会询问是否停止，并清理浏览器子进程。

## 通知地址

通知地址是可选功能。留空不会影响课程监控和选课。

程序会在以下情况调用通知地址：

- 发现空位；
- 选课成功；
- 登录态过期；
- 异常或提交失败触发熔断。

当前实现使用 HTTP GET 请求，并自动附加参数 `m`：

```text
https://example.com/course-notify?m=通知内容
```

如果填写的地址已经带有查询参数，程序会使用 `&m=...`。

该字段适合能够接收 GET 参数 `m` 的自建通知服务。大多数要求 POST 或特殊消息结构的微信、钉钉、飞书机器人不能直接填写，需要单独适配。

## 多门课程真正并行监控

多课程模式不是在一个循环里依次查询。点击“开始监控”后，每门课程都会立即启动一个独立工作进程，各自维护浏览器上下文、查询间隔、异常计数和提交熔断，因此不会等前一门课程完成后才开始下一门。

### 添加课程

推荐操作：

1. 点击“查看可选课程”或使用模糊筛选；
2. 在结果窗口选中课程；
3. 点击“加入并行监控”；
4. 对其他课程重复以上操作；
5. 主界面的“并行课程”会显示已加入数量；
6. 点击“管理并行课程”可以查看或删除课程。

也可以先把课程填入主界面，再点击“将当前课程加入列表”。同一个 lessonId 再次加入时会更新名称和容量，不会重复添加。

### 实时状态面板

主界面的“课程实时状态”表会分别显示每门课程：

- 当前状态：等待启动、监控中、已满、发现空位、提交失败、异常、熔断、登录过期、已完成或已停止；
- 当前人数与容量；
- 最近更新时间；
- 最新一条状态消息。

各课程状态独立更新，不需要从混合日志中判断是哪门课程。

### 成功状态持久化

某门课程选课成功后，调度器会原子更新 `config.json`：

- 将该课程标记为 `completed`；
- 记录完成时间 `completed_at`；
- 下次启动时自动跳过该课程；
- 其他尚未成功的课程继续保持待监控状态。

如需再次监控已完成课程，打开“管理并行课程”，选中课程后点击“重新设为待监控”。再次从课程结果中加入相同 lessonId 也会更新课程并恢复为待监控状态。

### 完成策略

| 策略 | 行为 |
|---|---|
| 所有课程分别抢到 | 所有课程从一开始就同时监控；某一门成功后只结束该门任务，其他课程继续独立运行 |
| 任意一门成功就停止全部 | 所有课程从一开始就同时监控；任意一门成功后立即停止其余任务，适合多门候选课只需要其中一门的情况 |

多课程会增加教务系统请求数量和本机 Chromium 进程数量。请控制课程数量并保持至少 60 秒的查询间隔，避免触发风控。

## 工作原理

每轮监控先调用 `std-count` 查询已选人数：

1. 已选人数大于或等于容量：等待下一轮；
2. 已选人数小于容量：判断为有空位；
3. `monitor` 模式只提醒；
4. `spam/grab` 模式依次调用 `add-request` 和 `add-drop-response` 提交选课；
5. 成功后退出，连续失败达到阈值则熔断停止。

非活跃时段只进行低频查询和提醒，**不会提交选课写请求**。

## 命令行使用

### Windows

```bat
.venv\Scripts\python grabbing.py --login
.venv\Scripts\python grabbing.py --list
.venv\Scripts\python grabbing.py
.venv\Scripts\python grabbing.py --lesson 123456 -t 90 --log run.log
```

### Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/playwright install chromium
.venv/bin/python grabbing.py --login
.venv/bin/python grabbing.py --list
.venv/bin/python grabbing.py
```

无图形界面的 Linux 服务器无法完成人工登录。应先在有桌面的机器运行 `--login` 生成 `auth.json`，再安全地复制到服务器项目目录。

## `config.json` 字段

| 字段 | 说明 |
|---|---|
| `student_id` | 学生关联 ID；留空自动解析 |
| `turn_id` | 选课轮次 ID；留空自动解析，每学期变化 |
| `target_lesson_id` | 目标教学班 lessonId，优先级最高 |
| `target_course_name` | 没有 lessonId 时使用的课程名称模糊匹配条件 |
| `limit_count` | 课程容量上限；自动监控前必须大于 0 |
| `interval_seconds` | 活跃时段查询基准间隔，建议不低于 60 秒 |
| `jitter_seconds` | 随机抖动秒数 |
| `heart_beat` | 非活跃时段查询间隔 |
| `active_hours` | 活跃时段，支持跨天；空字符串表示全天 |
| `max_errors` | 连续异常熔断阈值 |
| `max_grab_failures` | 连续选课提交失败熔断阈值 |
| `mode` | `monitor`、`spam` 或 `grab` |
| `notify_webhook_url` | 可选的 HTTP GET 通知地址 |
| `headless` | 是否隐藏 Chromium 窗口 |
| `disable_browser_sandbox` | 是否禁用浏览器沙箱，默认 `false` |

## 常见问题

### 点击按钮提示缺少 Playwright 或 Requests

在项目目录执行：

```bat
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\playwright install chromium
```

### 右上角一直显示“尚未生成登录态”

点击“登录教务系统”并完整完成统一身份认证。确认项目目录中生成了 `auth.json`。

### 登录态已过期

重新点击“登录教务系统”，生成新的 `auth.json`。

### 显示“已满 x/y”

这是正常状态，表示当前已选人数等于或超过配置容量，程序会继续等待。

### 一直显示人数解析失败

教务系统接口结构可能发生变化。停止程序并保留日志中的 `std-count` 原始片段，检查 `_parse_std_count` 的兼容逻辑。

### 课程名称、授课对象或代码看起来不对

课程名称来自 `course.nameZh/nameEn`；顶层 `nameZh/nameEn` 是授课对象。教学班代码和课程代码也是不同字段。请关闭并重新打开最新版本的助手。

### 课程容量没有自动填入

部分接口数据可能不含容量。请以教务系统页面显示的准确容量为准，手动填写后保存。

### 被风控或账号受限

立即停止程序，降低查询频率或改为手动操作，并按学校要求处理。

## 安全说明

- 不要分享或提交 `auth.json`；
- 不要在公开仓库提交包含学号或私人通知地址的 `config.json`；
- 不要关闭浏览器沙箱，除非受限 Linux 环境确有需要；
- 不要设置过短的查询间隔；
- 使用前确认目标课程、lessonId 和容量完全正确。
